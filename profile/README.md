## 👋 About Submify

Submify is an **automated backlink submission tool built for Codex**. It ships with a curated library of **7,000+ quality backlinks** — AI and startup directories, SaaS directories, blog-comment sites, product-launch platforms and guest-post sites — sorted by category and tag. Pick the links you want, add them to your website project, copy one prompt into Codex, and Codex opens each site, fills the form, verifies the email and submits for you.

No more registering and filling forms one by one. Submify fetches verification codes automatically from your Google or site mailbox, and you can schedule Codex to keep pushing submissions forward (for example every 30 minutes). Every link's status is tracked in one dashboard, with import and export.

Prefer to submit by hand? The Chrome extension opens a profile panel with **Ctrl + E** so you can fill product fields in a click. Submify also exposes an **MCP server**, so AI agents can manage websites, add backlinks and check submission progress directly.
